# Lokale bouwvoorbeelden

Open index.html in een moderne browser. Geen installatie nodig. Bron: index.html, style.css, app.js en fixtures.js. fixtures.json is dezelfde dataset als bewerkbaar bronbestand. Houd fixtures.js gelijk als je de JSON wijzigt. Exporteer oefendata voordat je die wist.

Test intake invullen en herladen; briefing compleet/onvolledig/leeg; CRM dubbel event/ontbrekende input/stop/herstel; support bekende/onbekende/gevoelige vraag; calculatie en data-export. Opslag is alleen deze browser en biedt geen klantisolatie. Dit is een lokale demo zonder login, betaalfunctie, echt CRM of modelverbinding. Live checklist: ../../start/LIVE-CHECKLIST.md.

De getoonde HTML gebruikt textContent voor invoerweergave. Voer eigen gegevens in als oefendata. Voor echte klantgegevens is een afzonderlijke productieomgeving met servercontroles nodig.
