## Volledige historische spreektekst

Deze security-audit-skill kan helpen om verdachte code gericht te onderzoeken. Ook deze skill moet eerst zelf worden beoordeeld. We voegen hem daarna toe aan de bronreview uit les 4.4.

Pak een bevinding met een exact bestand en regelnummer. Lees de code eromheen en volg welke input de functie ontvangt. Noteer welke bestanden of netwerkbestemmingen bereikbaar zijn. Een melding krijgt daarmee een concrete verklaring.

Vergelijk de uitkomst met het oorspronkelijke SkillSpector-rapport. Bewaar beide, ook als je een melding als false positive beoordeelt. Schrijf op waarom en welke begrenzing je hebt gecontroleerd. Een incomplete scan blijft een open punt. Het eindresultaat van deze demo is een besluit met bewijs, niet een groen vinkje zonder onderbouwing.
