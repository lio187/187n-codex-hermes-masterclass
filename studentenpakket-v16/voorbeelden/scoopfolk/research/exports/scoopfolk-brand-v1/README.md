# Scoopfolk identity kit — V1

Start with **brandbook.pdf** or **brandbook.html**. The SVG logo masters are the authoritative artwork.

## Contents

- `logos/`: original vector wordmark and scoop symbol in six colors, transparent PNG exports at 3×, category lockup and avatar.
- `brandbook.pdf`: 12-page identity guide. `brandbook.html`: editable source with local assets.
- `images/packaging-concept.png`: AI-generated packaging study, not a finished label or manufacturing artwork.
- `images/initial-concept-board.png`: early AI exploration retained for provenance; it is not the authoritative logo, color or usage guide.
- `brand-tokens.css` and `brand-tokens.json`: exact digital colors and starter interface tokens.
- `source/`: reproducible logo and book generation scripts; local rendering depends on the existing Playwright installation documented in the scripts.
- `PROMPTS.md`: generation prompts and provenance.

## Usage

Use the SVG masters for print and layout. Their wordmark and symbol are original geometry, with no font dependency. The category descriptor uses Arial; export text to outlines in final print production if required by your supplier. The HTML uses Arial Rounded MT Bold for headings with Arial fallback and Arial/Helvetica for body. Font files are not included or licensed by this delivery.
