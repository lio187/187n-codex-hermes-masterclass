# Officiële bronnen en opnamevoorbereiding

Gecontroleerd op 21 september 2026. Controleer de zichtbare versie vóór opname.

## Codex in de actuele desktopapp
[Codex in de actuele desktopapp](https://help.openai.com/en/articles/20001276/)

De actuele downloadroute kan de gecombineerde ChatGPT-desktopapp openen. Kies daar Codex. Neem de werkelijk zichtbare UI op.

## Composio Connect
[Composio Connect](https://docs.composio.dev/docs/composio-connect)

MCP-endpoint https://connect.composio.dev/mcp; verbind de benodigde ondersteunde apps. Eén verbinding geeft niet automatisch ieder account toegang.

## Hermes Desktop
[Hermes Desktop](https://hermes-agent.nousresearch.com/docs/user-guide/desktop)

Download via de officiële Desktop-productpagina; gebruik geen ongecontroleerd remote installatiescript.

## Hermes-profielen
[Hermes-profielen](https://hermes-agent.nousresearch.com/docs/user-guide/profiles)

Gebruik aparte cursusprofielen; volg de actuele profielinrichting bij de aanwezige versie.

## Hermes scheduling
[Hermes scheduling](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron)

Leg projectpad en tijdzone expliciet vast; test vóór activering.

## Shopify theme-architectuur
[Shopify theme-architectuur](https://shopify.dev/docs/storefronts/themes/architecture)

Sections, snippets, assets, layout en templates hebben afzonderlijke functies.

## Shopify JSON templates
[Shopify JSON templates](https://shopify.dev/docs/storefronts/themes/architecture/templates/json-templates)

Gebruik JSON templates om sections en hun instellingen per pagina samen te stellen.

## Shopify CLI
[Shopify CLI](https://shopify.dev/docs/storefronts/themes/tools/cli)

Gebruik de actuele ondersteunde theme-development-route op een ongepubliceerd theme.

## Shopify Rollouts
[Shopify Rollouts](https://help.shopify.com/en/manual/markets/rollouts)

Controleer Markets > Rollouts en de winkelvereisten voor een launch of experiment.

## Atria MCP
[Atria MCP](https://docs.tryatria.com/docs/mcp-quickstart)

Endpoint https://api.tryatria.com/mcp via OAuth/StreamableHTTP; actuele toolschemas zijn leidend.

Atria: de eerdere accountproef had een uitgeputte allowance. Dit pakket bevat geen live opgehaalde advertenties. GitHub: vastgelegde README/metadata-review is geen installatievrijgave of geslaagde runtimeproef.
