# 0.3 · Uitgebreide achtergrond

Naslag bij de oorspronkelijke V8-uitleg. Niet extra voorlezen: de compacte actuele spreektekst en opdrachten staan in de les. Bij verschillen geldt de actuele les.

Hier begint je eigen werkruimte. Het pakket staat bij deze cursus als een vaste release. Een release is een bewaarde versie. Daardoor kunnen we later precies terugvinden welke bestanden jij gebruikt. Download dus de versie uit de les, niet zomaar de nieuwste branch omdat daar een recenter datum bij staat.

Voordat we iets uitvoeren, leggen we de repository-URL en de volledige commitcode vast. Die lange code identificeert de bronversie. Pak de ZIP uit in een eigen map, bijvoorbeeld AI-team-v8 in je documenten. Je hoeft de map niet naar mijn gebruikersnaam te vernoemen. Alle paden in het pakket horen vanaf jouw projectmap te werken.

Nu komt de controle. Nieuwe broncode en skills laten we scannen met NVIDIA SkillSpector. Daarnaast lezen we wat de code werkelijk doet: welke scripts bij installatie draaien, welke websites worden benaderd, welke gegevens worden gelezen en welke dependencies nodig zijn. De scanner helpt ons locaties vinden. Hij geeft geen garantie dat een complete applicatie veilig of foutloos is.

De korte opdracht staat in het lesbestand. De agent moet eerst alleen controleren. Een download is nog geen installatie. Op mijn Mac gebruik ik daarvoor een vooraf gecontroleerde wrapper. Die wrapper staat niet vanzelf op jouw computer. Volg daarom de scannerroute uit de startgids. Ontbreekt de scanner of is de scan incompleet, dan stoppen we voordat er code wordt uitgevoerd.

Open het rapport samen met de bronreview. Bij een ernstige melding kijk je naar de exacte regel en wat die functie nodig heeft. Je verwijdert een melding niet omdat je graag verder wilt. Soms is gevoelige toegang noodzakelijk en goed begrensd; dan leg je de reden en maatregelen vast. Een onverklaarde ernstige melding blijft een blokkade.

Na deze controle openen we de projectmap in Codex. Kijk links of je START-HIER, context, case en lessen kunt vinden. Vraag de agent alleen om de startgids en het bedrijfsprofiel te lezen en kort te zeggen wat nog ingevuld moet worden. Als hij een bestand niet vindt, controleer je de geopende map. Vaak zit je een map te hoog of juist in een submap.

Je hebt nu één duidelijke plek voor deze cursus. Bewaar het oorspronkelijke scanrapport buiten de download en bewaar de versiegegevens. Als je later een update ophaalt, herhaal je de controle vóór de nieuwe code draait. We gaan nu de context invullen die al je volgende opdrachten persoonlijk maakt.
