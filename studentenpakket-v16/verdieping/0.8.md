# 0.8 · Uitgebreide achtergrond

Naslag bij de oorspronkelijke V8-uitleg. Niet extra voorlezen: de compacte actuele spreektekst en opdrachten staan in de les. Bij verschillen geldt de actuele les.

Je werkplek staat. Nu laat ik je zien waar de rest van de cursus op aansluit. Een skill bewaart een werkwijze. Browsergebruik laat de agent een pagina controleren. Computer use kan met zichtbare apps werken. Een automation start een taak volgens een trigger. Die woorden betekenen dus verschillende dingen.

Open één skillbestand. Hier lees je wanneer je de skill gebruikt, welke input nodig is en wat er uit moet komen. Dat bestand downloaden is nog niet hetzelfde als laden in de app. We controleren later expliciet of Codex of Hermes de gekozen skill werkelijk gebruikt. Je hoeft vandaag niet al je skills tegelijk te installeren.

Bij browsercontrole wil ik een echte handeling zien. Open de oefenpagina, vul een testveld in en controleer wat er gebeurt. Een screenshot van de voorkant bewijst bijvoorbeeld niet dat een formulier zijn gegevens bewaart. Je kijkt naar de actie die voor de gebruiker belangrijk is.

Als Record & Replay in jouw versie beschikbaar is, kun je een handeling voordoen en die als basis voor een werkwijze gebruiken. Op Windows of een account waar die functie ontbreekt, doen we hetzelfde met beschreven stappen, screenshots en feedback. Het leerdoel blijft gelijk: de agent moet begrijpen welke handeling je herhaald wilt uitvoeren.

Een geplande taak vraagt ook een plek waar hij kan draaien. Als je een lokaal Hermes-team op een uitgeschakelde computer zet, kan die computer geen taak uitvoeren. Later kiezen we bewust welke machine aanblijft, hoe de gateway start en waar de logs staan. Remote toegang betekent dat je die machine op afstand kunt bereiken; het maakt de onderliggende taak niet vanzelf betrouwbaar.

Maak nu een kleine functieskaart. Zet bij elke functie of die beschikbaar is, nog ingesteld moet worden of voor jouw eerste opdracht niet nodig is. Je hoeft niet alles tegelijk te beheersen. We hebben nu genoeg om aan de inhoud te beginnen: research die voorkomt dat je straks mooie output maakt voor een aanbod dat niemand begrijpt.
