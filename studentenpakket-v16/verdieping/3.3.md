# 3.3 · E-mailagent: vier flows voor je merk

Je klant heeft net besteld en krijgt daarna alsnog een mail over zijn verlaten winkelmand. Zo'n fout willen we in de test al vinden.

We tekenen de flow: welk event start de mail, hoeveel tijd zit ertussen en welk event stopt de opvolging? Een aankoop hoort in dit voorbeeld de verlaten-winkelmandmail uit te sluiten.

Laat de E-mailagent de inhoud voorbereiden met je productcontext. Test de route met je eigen testadres en controleer wat er gebeurt wanneer de aankoop tussendoor binnenkomt.

Kijk ook naar de log. Je wilt kunnen volgen waarom een mail wel of juist niet is verstuurd. Dan kun je de flow controleren op de gebeurtenissen die voor je klant tellen.

Open Shopify Messaging voor de marketingflows en houd de orderbevestiging apart. Voor de refill gebruiken we een bevestigde datum uit Shopify Subscriptions. Controleer bestaande meldingen voordat je een extra bericht toevoegt.

Shopify Flow kan helpen met beschikbare maatwerkcondities. Een workflowtest verstuurt geen echte mail: controleer de ontvangen testmail afzonderlijk. Test ook een dubbel event en een afmelding, uitsluitend met je eigen testadres.
